# Robust Staffing of Walk-In Clinics under Demand Uncertainty: A Simulation-Optimization Approach with Exact Benchmarking

This repository contains the data, algorithms, and interactive artifacts for the paper evaluating robust staffing configurations in walk-in clinics under demand uncertainty. 

The framework couples a custom Discrete-Event Simulation (DES) engine with multi-objective search algorithms (NSGA-II, Weighted-Sum GA, and Exhaustive Enumeration) to evaluate trade-offs between manpower costs, waiting times, and service levels.

###  Getting Started
All reproducible code is located in the `Scripts/` folder and can be run instantly via Google Colab—no local installation required:
* **Notebook 01-03:** Core methodology, nominal vs. robust formulations, and reliability benchmarking.
* **Notebook 04 (Web App):** Launches the interactive Decision Support System (DSS) Streamlit dashboard.
